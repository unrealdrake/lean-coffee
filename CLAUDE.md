# Lean Coffee — доска для встреч

Сайт: https://unrealdrake.github.io/lean-coffee/ (GitHub Pages, ветка `main`, корень репозитория).
Репозиторий: https://github.com/unrealdrake/lean-coffee — весь проект это один файл `index.html`, без сборки.
После правок: коммит и `git push` в `main`; сайт обновляется примерно через минуту. Браузер может держать старую версию до 10 минут — проверять с Ctrl+Shift+R.

Общаемся по-русски. Пользователь не хочет, чтобы коммиты делались через браузер (веб-интерфейс GitHub) — только git из этой папки.

## Формат встречи (как пользователь проводит Lean Coffee)
1. Ведущий рассказывает пару слов о Lean Coffee. Обычно задана общая тема.
2. 5 минут — все набрасывают темы.
3. 3 минуты — голосование, у каждого 3 голоса (можно все на одну тему).
4. Самые популярные темы уходят в «К обсуждению».
5. 8 минут на тему, потом голосование «продолжаем / дальше»:
   большинство «за» — ещё 5 минут, поровну — ещё 2 минуты, иначе следующая тема.

## Как устроено
- P2P без сервера и без аккаунтов: Trystero 0.27.0, импорт `https://cdn.jsdelivr.net/npm/trystero@0.27.0/+esm` (стратегия nostr). `esm.run` не использовать.
- Ведущий — admin через `roles({selfAsAdmin:true})`. ID комнаты вида `база~ключ_админа`; участники заходят по `?r=<roomId>` с `roles()`.
  Ведущего узнаёт по постоянной identity браузера; комната ведущего хранится в `localStorage['lc-my-room']`, поэтому голый адрес открывает его комнату.
- `room.makeState('board')` — общее состояние, пишет только ведущий (`setB`). Копия у ведущего в `localStorage['lc-board:'+link]` на случай перезагрузки.
- `room.makeUserState('mine')` — слот каждого участника: `{sid, topics[], picks{}, thumb}`. Ведущий переносит его в board функцией `merge` (с проверками: длина текста, ≤3 голоса, фаза).
- `localMine` — мгновенное локальное отображение своих действий, не дожидаясь подтверждения сети.
- `maxBytes`: board 65536 (это максимум библиотеки — больше нельзя, иначе падает при запуске), mine 16384. Итоги по теме обрезаются до 1000 символов.
- Рендер: `view()` строит HTML, `morph()` патчит DOM без мигания (не заменять на innerHTML — карточки начинали моргать).
- Таймер: `endsAt` (время ведущего) / `left` при паузе / `dur`.

## Тестирование
- `?guest=1` — одноразовая identity (новый участник в том же браузере). Вкладки одного профиля без этого — один и тот же пользователь.
- `?new=1&guest=1` — отдельная тестовая комната, не трогает настоящую комнату ведущего.
- Для проверки логики без сети удобно подменить `joinRoom/roles` моком (jsdom/playwright).

## Решения по дизайну (по отзывам пользователя)
- Светлая тема: белый фон, шапка градиент персик→розовый→сиреневый, пастельные карточки, акцент #e0307c, таймер #0fa9ad. Тёмная неоновая версия («в стиле GTA 6») была «вырвиглазной» и слишком тёмной — не возвращать.
- На карточках обычный читаемый шрифт (Manrope 700), рукописный Caveat убран — плохо читался. Заголовки Unbounded.
- Этапы встречи — степпер с номерами и линией (пройденные с галочкой, текущий розовый), а не «пилюли», похожие на фильтры.
- Точки голосов показывают голоса ВСЕХ: тёмные — свои, розовые — чужие, подпись «N голосов · ваших K». Изначально были только свои — пользователь считал это багом синхронизации.
- Ссылка для участников постоянная, «Новая сессия» просто очищает доску.
